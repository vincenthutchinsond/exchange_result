# Обработка результатов обмена

Модуль `exchange.py` принимает записи о результатах обмена данными
между системами и приводит их к формату программы.

Запуск обработки файла `data/results.json`:

    python run.py

## Правила обработки

Поля записи: `date` (дата), `amount` (сумма), `status` (статус). Все поля обязательны.

Названия полей нормализуются: убираются пробелы, регистр не учитывается,
русские варианты «Дата», «Сумма», «Статус» приводятся к `date`, `amount`, `status`.

Пустыми считаются: отсутствующее поле, значение null, пустая строка и строка, состоящая только из пробелов. Значения проверяются после удаления пробелов.

Преобразования:

- дата `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД` → `ГГГГ-ММ-ДД`;
- сумма `1 250,50` → `1250.5` (пробелы убираются, запятая заменяется точкой);
- статус «успешно» / «ошибка» / «в обработке» → `success` / `error` / `pending`.

Сообщение об ошибке указывает поле и причину, например:

    Поле «amount»: ожидается число, получено «сто рублей».
